# Yandex Maps Parser

Тестовое приложение на Laravel + Vue 3 для получения информации об организации из Яндекс Карт.

Пользователь вводит ссылку на организацию, приложение сохраняет её и запускает парсинг в очереди. После завершения данные сохраняются в базу и отображаются в интерфейсе.

## Стек

* PHP 8.5+
* Laravel 13
* Laravel Sanctum
* Laravel Queue
* Mysql
* Vue 3
* Vue Router
* Axios
* Vite

## Что умеет приложение

* Авторизация пользователя.
* Приём обычных и коротких ссылок Яндекс Карт.
* Получение названия организации и рейтинга.
* Получение отзывов.
* Отображение прогресса парсинга.
* Пагинация отзывов по 50 записей.
* До 600 отзывов за один запуск.
* Повторные попытки при временных ошибках.
* Защита от повторного запуска одной и той же задачи.
* Защита от дублирования отзывов.
* Автоматические тесты.

## Как это работает

Упрощённо:

```text
Vue
 ↓
Laravel API
 ↓
Сохранение организации
 ↓
Queue Job
 ↓
Parser
 ↓
Яндекс Карты
 ↓
Сохранение данных в БД
 ↓
Vue получает результат
```

Парсинг выполняется в очереди, поэтому HTTP-запрос не ждёт завершения всей операции.

Frontend периодически запрашивает статус парсинга и показывает текущий прогресс. После завершения polling останавливается.

## Парсер

Парсер разделён на две части:

* `Parser` отвечает за получение страниц и общий процесс парсинга.
* `ResponseParser` отвечает за разбор полученного HTML.

Так проще тестировать отдельные части и изменять логику разбора страницы.

Отзывы сохраняются в БД через `upsert`.

В качестве ключа используются:

```text
organization_id + external_id
```

Поэтому при повторном парсинге существующие отзывы обновляются, а новые добавляются без создания дублей.

## Ошибки и повторные попытки

Приложение обрабатывает основные проблемы при получении данных:

* `403` / `429`;
* ошибки `5xx`;
* CAPTCHA;
* пустые ответы;
* изменение структуры страницы.

Временные ошибки приводят к повторному запуску Queue Job.

Для Job настроено до 3 попыток с задержками между ними.

## Установка

### 1. Установить зависимости

```bash
composer install
npm install
```

### 2. Создать `.env`

```bash
cp .env.example .env
```

### 3. Сгенерировать ключ приложения

```bash
php artisan key:generate
```

### 4. Создать SQLite

```bash
touch database/database.sqlite
```

В `.env`:

```env
DB_CONNECTION=sqlite
```

### 5. Выполнить миграции и заполнить тестовые данные

```bash
php artisan migrate --seed
```

### 6. Запустить Laravel

```bash
php artisan serve
```

### 7. Запустить frontend

В отдельном терминале:

```bash
npm run dev
```

### 8. Запустить очередь

Ещё в одном терминале:

```bash
php artisan queue:work
```

После этого открыть:

```text
http://127.0.0.1:8000
```

## Ограничения

Данные получаются непосредственно со страниц Яндекс Карт, а не через официальный API.

Поэтому приложение зависит от структуры страницы. Если Яндекс изменит её, парсер может потребовать доработки.

Логика разбора вынесена в отдельный `ResponseParser`, поэтому такое изменение можно локализовать в одном месте.
